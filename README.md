## **Резюме проекта на текущем этапе**

Мы создали базовую структуру проекта на **NestJS**, используя **TypeScript** и **TypeORM**. Проект разделен на функциональные модули (`auth` и `users`), что делает его модульным и поддерживаемым. Каждый модуль содержит контроллеры, сервисы, DTO, сущности и интерфейсы для реализации своей функциональности.

## **Описание модулей**

### **1. `auth`**

Модуль аутентификации. Отвечает за регистрацию, вход и выдачу JWT-токенов.

#### **Компоненты**:

- **`auth.module.ts`**: Основной модуль, регистрирует все компоненты.
- **`auth.controller.ts`**: Обрабатывает запросы на вход и регистрацию.
- **`auth.service.ts`**: Содержит логику для аутентификации и регистрации.
- **`dto/`**: Определяет структуру данных для запросов на вход и регистрацию.
  - `login.dto.ts`: Данные для входа.
  - `register.dto.ts`: Данные для регистрации.
- **`entity/`**: Содержит сущность `User`, которая описывает таблицу пользователей в базе данных.
  - `user.entity.ts`: Сущность пользователя.
- **`interface/`**: Содержит интерфейсы для типизации данных.
  - `user.interface.ts`: Интерфейс пользователя.
- **`strategy/`**: Содержит стратегию аутентификации через JWT.
  - `jwt.strategy.ts`: Стратегия для проверки JWT-токенов.
- **`guard/`**: Содержит гуарды для защиты маршрутов.
  - `jwt.guard.ts`: Гуард для проверки JWT-токенов.

---

### **2. `users`**

Модуль для работы с пользователями. Отвечает создание, получение, обновление и удаление пользователей.

#### **Компоненты**:

- **`users.module.ts`**: Основной модуль, регистрирует все компоненты.
- **`users.controller.ts`**: Обрабатывает запросы на CRUD-операции с пользователями.
- **`users.service.ts`**: Содержит логику для работы с пользователями.
- **`dto/`**: Определяет структуру данных для запросов на создание и обновление пользователей.
  - `create-user.dto.ts`: Данные для создания пользователя.
  - `update-user.dto.ts`: Данные для обновления пользователя.
- **`entity/`**: Содержит сущность `User`, которая описывает таблицу пользователей в базе данных.
  - `user.entity.ts`: Сущность пользователя.
- **`interface/`**: Содержит интерфейсы для типизации данных.
  - `user.interface.ts`: Интерфейс пользователя.

---

### **3. `shared`**

Общие модули, которые используются в разных функциональных частях приложения.

#### **Компоненты**:

- **`database/`**: Модуль для работы с базой данных.
  - `database.module.ts`: Настройка подключения к базе данных.
  - `database.service.ts`: Сервис для работы с базой данных.
- **`exceptions/`**: Обработка исключений.
  - `http-exception.filter.ts`: Фильтр для обработки HTTP-исключений.
- **`interceptors/`**: Перехватчики.
  - `logging.interceptor.ts`: Перехватчик для логирования запросов.
- **`decorators/`**: Декораторы.
  - `user.decorator.ts`: Декоратор для извлечения данных пользователя из запроса.
- **`utils/`**: Утилиты.
  - `validation.pipe.ts`: Пайп для валидации данных.
